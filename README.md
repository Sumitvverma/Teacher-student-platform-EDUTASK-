## EduConnect - Teacher & Student Platform
A streamlined web app connecting teachers and students for assignment tracking and course management.
## Features

* Role Logins: Separate dashboards for teachers and students.
* Course Hub: Teacher material uploads and student downloads.
* Assignments: Easy digital submission and grading tracking.

## Tech Stack

* Frontend: React.js / Tailwind CSS
* Backend: Node.js / Express.js
* Database: MongoDB
 
## Quick Start## 1. Setup

git clone https://github.com
cd project
npm install

## 2. Environment (.env)

PORT=5000
MONGO_URI=your_database_url
JWT_SECRET=your_secret_key

## 3. Run

npm run dev
